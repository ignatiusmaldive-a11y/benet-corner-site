# CHECKLIST DE CONSTITUCIÓ I POSADA EN MARXA

## Abans de signar

- [ ] Confirmar almenys tres persones fundadores.
- [ ] Comprovar la disponibilitat de la denominació exacta.
- [ ] Confirmar domicili social real i correu de l’associació.
- [ ] Revisar els estatuts amb una persona experta en dret associatiu català.
- [ ] Identificar les persones inicials de Presidència, Secretaria i Tresoreria.
- [ ] Fixar la quota inicial o deixar-la pendent d’aprovació de la primera Assemblea.
- [ ] Preparar una còpia reservada dels documents d’identitat.
- [ ] Preparar els consentiments de dades, separats de qualsevol document públic.

## Dia de constitució

- [ ] Signar `01_acta_fundacional.md` totes les persones fundadores.
- [ ] Signar `02_estatuts.md` totes les persones fundadores o, com a mínim, Presidència i Secretaria segons el tràmit.
- [ ] Signar `03_acceptacio_carrecs.md` totes les persones designades.
- [ ] Completar `04_registre_inicial_socis.md` en una còpia restringida.
- [ ] Recollir `05_consentiment_dades.md` de cada persona.
- [ ] Adoptar `06_acta_junta_inicial_autoritzacio_litigi.md` només després de confirmar la Junta i l’estratègia amb l’advocat/ada.

## Presentació al Registre d’Associacions

- [ ] Presentar electrònicament l’acta fundacional i els estatuts.
- [ ] Adjuntar documents d’identitat de les persones fundadores segons el tràmit.
- [ ] Pagar la taxa vigent que indiqui el tràmit oficial —la pàgina consultada indica **63,80 €**— i conservar el justificant.
- [ ] Guardar el rebut electrònic, número d’expedient, data i còpia exacta presentada.
- [ ] Respondre dins de termini qualsevol requeriment d’esmena.
- [ ] Guardar la resolució o el certificat d’inscripció quan arribi.

## NIF i administració

- [ ] Presentar el Model 036 per obtenir el NIF provisional, amb l’acta, els estatuts i la representació.
- [ ] Guardar la targeta o certificat del NIF provisional.
- [ ] Després de la inscripció, presentar el Model 036 per al NIF definitiu.
- [ ] Obrir un compte bancari de l’associació amb dues signatures per a pagaments extraordinaris.
- [ ] Adoptar un pressupost inicial i un sistema de justificants.
- [ ] Preparar el certificat digital de representant quan sigui possible.

## Expedient judicial urgent

- [ ] Confirmar amb l’advocat/ada el còmput exacte del termini de l’expedient 26PL17180.
- [ ] Tenir l’acta de la Junta i el certificat preparats abans de contractar.
- [ ] Obtenir el pressupost escrit de l’advocat/ada i del/de la procurador/a.
- [ ] Confirmar si hi ha taxa judicial i qui serà la part recurrent.
- [ ] Confirmar si es demanaran mesures cautelars i quin dipòsit o cost pot implicar.
- [ ] Preparar el poder o apoderament apud acta.
- [ ] Afegir, si l’advocat/ada ho recomana, persones físiques co-claimants amb consentiment informat.
- [ ] Presentar amb marge de seguretat, no l’últim dia.
