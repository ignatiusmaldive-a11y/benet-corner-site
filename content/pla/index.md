El pla està pensat per a una organització petita: poques eines, publicació estàtica amb GitHub Pages i revisió humana abans de fer canvis públics.

## Objectius

1. Consolidar una entitat o grup de treball amb rols clars.
2. Recollir documents, testimonis, fotografies i calendari d'activitats.
3. Redactar una proposta d'ús comunitari amb manteniment, impacte i governança.
4. Preparar comunicacions públiques breus i comprovables.
5. Fer que Hermes ajudi a crear esborranys, no a publicar sense revisió.

## Criteris

- Textos curts, verificables i fàcils de traduir.
- Una pàgina per tema, amb data i responsable de revisió.
- Canvis per pull request quan el contingut sigui sensible.
- Separació entre contingut públic i documentació operativa privada.
