El projecte prova una versió del web basada en Blowfish, un tema Hugo pensat per publicar contingut estructurat amb cerca, seccions, etiquetes i pàgines d'autor.

Aquesta estructura facilita que diverses persones col·laborin amb GitHub Pages i que Hermes pugui preparar esborranys de pàgines Markdown per revisar abans de publicar.
