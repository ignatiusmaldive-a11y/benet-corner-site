## Criteri editorial

- **Documentat:** hi ha una font pública o un document identificable.
- **Proposta:** forma part del projecte veïnal, però necessita acord, permisos o finançament.
- **Estimació:** import o calendari orientatiu que s'ha de validar.
- **Pendent:** manca una decisió, una dada o una confirmació externa.

La informació sensible, les dades personals i l'estratègia jurídica confidencial no es publiquen. Les plantilles disponibles són esborranys i no substitueixen assessorament professional.
